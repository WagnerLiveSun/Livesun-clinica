# Instruções para Criar Apresentação PowerPoint
## LiveSun Clinicas - Guia Educativo

---

## 📋 Visão Geral

Este documento fornece instruções detalhadas para criar uma apresentação PowerPoint educativa baseada no arquivo `APRESENTACAO_FUNCIONALIDADES.md`. A apresentação deve permitir que usuários aprendam a usar o sistema apenas com os slides.

---

## 🎨 Design e Estilo

### Cores da Marca
- **Primária:** Dourado/Sunset (#FFD700 ou similar)
- **Secundária:** Azul escuro (#1E3A8A)
- **Fundo:** Branco ou cinza claro
- **Texto:** Preto ou cinza escuro

### Fontes
- **Títulos:** Arial Black, Calibri Bold, ou similar (24-36pt)
- **Subtítulos:** Arial, Calibri (18-24pt)
- **Corpo:** Arial, Calibri (14-18pt)
- **Código/Mono:** Consolas, Courier New (12-14pt)

### Layout Padrão
- **Título:** Topo, alinhado à esquerda
- **Conteúdo:** Corpo, com espaço em branco
- **Imagens:** Direita ou centro, quando aplicável
- **Rodapé:** Número do slide e logotipo

## 🖼️ Instruções para Screenshots

### Ferramentas Recomendadas
- **Windows:** Snipping Tool, Win+Shift+S
- **Mac:** Cmd+Shift+4
- **Linux:** gnome-screenshot, Shutter

### Screenshots Necessários
1. **Tela inicial** - Sem login
2. **Dashboard** - Com dados de exemplo
3. **Agenda** - Visão diária/semanal
4. **Formulário de cliente** - Cadastro completo
5. **Prontuário** - Com evoluções
6. **Evolução clínica** - Com fotos
7. **Relatórios** - Gráficos de faturamento
8. **Configurações** - Painel de configurações

### Padrão de Screenshots
- **Resolução:** 1920x1080 ou similar
- **Formato:** PNG (qualidade)
- **Recorte:** Remova barras do navegador
- **Dados:** Use dados de exemplo realistas
- **Privacidade:** Remova dados sensíveis

## ⚡ Interatividade

### Animações Recomendadas
- **Aparecer:** Para listas (aparecer item por item)
- **Deslizar:** Para transições entre seções
- **Zoom:** Para destacar screenshots importantes
- **Fade:** Para mudanças sutis

### Não Exagerar
- Use animações com moderação
- Mantenha foco no conteúdo
- Evite distrações desnecessárias
- Teste timing das animações

### Navegação
- **Hyperlinks:** Para seções relacionadas
- **Botões "Voltar":** Para navegação fácil
- **Índice:** Slide com links para seções
- **Sumário:** Recapitulação ao final

## 🎤 Apresentação

### Roteiro Sugerido
```
1. Bem-vindo e introdução (2 min)
2. Visão geral do sistema (3 min)
3. Demonstração do dashboard (2 min)
4. Configuração inicial (4 min)
5. Fluxo de agendamento (3 min)
6. Gestão de clientes (3 min)
7. Prontuários e evoluções (4 min)
8. Comunicações (2 min)
9. Financeiro (2 min)
10. Relatórios (2 min)
11. Dicas e suporte (3 min)
12. Encerramento (1 min)
```

### Padrão de Fala
- **Início:** "Vamos começar com..."
- **Transição:** "Agora vamos ver..."
- **Ênfase:** "É importante notar que..."
- **Conclusão:** "Para resumir..."
- **Perguntas:** "Alguma dúvida até aqui?"

### Dicas de Apresentação
- **Pratique:** Rehearse antes de apresentar
- **Tempo:** Respeite o tempo estimado
- **Engajamento:** Faça perguntas retóricas
- **Clareza:** Fale de forma simples e direta
- **Confiança:** Conheça bem o material

## 🎯 Objetivos Educacionais

### Após a Apresentação, o Usuário Deve:
- [ ] Entender o propósito do sistema
- [ ] Saber acessar e navegar na interface
- [ ] Conhecer as funcionalidades principais
- [ ] Ser capaz de realizar tarefas básicas
- [ ] Saber onde encontrar ajuda
- [ ] Sentir-se confiante para usar o sistema

### Métricas de Sucesso
- **Compreensão:** Usuário consegue explicar o sistema
- **Aplicação:** Usuário consegue realizar tarefas básicas
- **Independência:** Usuário consegue usar sem ajuda constante
- **Satisfação:** Usuário sente-se confiante com o sistema
